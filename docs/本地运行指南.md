# 本地运行指南（零基础版）

> 本文档面向完全不了解 Git 的同学，手把手教你把代码下载到本地并跑通。

---

## 第一步：下载代码

### 方法：从 GitHub 下载 ZIP 压缩包

1. 打开浏览器，访问项目地址：

   **https://github.com/using03/club-system**

2. 如果页面显示的分支不是最新的，点击左上角的分支选择器，选择 `cursor/development-environment-setup-3dfd` 分支

3. 点击绿色的 **「Code」** 按钮

4. 在弹出的菜单中，点击 **「Download ZIP」**

5. 下载完成后，右键点击 ZIP 文件，选择 **「解压到当前文件夹」**

6. 你会得到一个文件夹，里面包含所有代码

解压后的文件夹结构：
```
club-system/
├── server/              ← 后端代码（Node.js）
├── client/              ← 前端代码（CLI版本，可忽略）
├── client-hbuilderx/    ← 前端代码（HBuilderX版本）✅ 用这个
├── docs/                ← 文档
├── README.md
└── ...
```

## 第二步：安装必要软件

你的电脑需要安装以下 4 个软件：

### 2.1 安装 Node.js

1. 访问 https://nodejs.org/zh-cn
2. 下载 **LTS（长期支持版）**（推荐 18.x 或 20.x）
3. 双击安装，一路点「下一步」即可
4. 验证安装：打开 **命令提示符**（Win+R，输入 cmd，回车），输入：
   ```
   node -v
   npm -v
   ```
   看到版本号就说明安装成功。

### 2.2 安装 MongoDB

1. 访问 https://www.mongodb.com/try/download/community
2. 下载 **MongoDB Community Server**（选 Windows MSI 包）
3. 安装时勾选 **「Install MongoDB as a Service」**（这样开机自动启动）
4. 安装完成后 MongoDB 会自动在后台运行

> 💡 如果不想安装本地 MongoDB，也可以用免费云数据库 MongoDB Atlas：
> https://www.mongodb.com/cloud/atlas/register
> 注册后创建免费集群，获取连接字符串，替换 server/.env 中的 MONGODB_URI

### 2.3 安装 HBuilderX

1. 访问 https://www.dcloud.io/hbuilderx.html
2. 下载 **App开发版**（包含uni-app插件）
3. 解压即可使用（免安装）

### 2.4 安装微信开发者工具

1. 访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 下载并安装 **稳定版**
3. 安装后用微信扫码登录

## 第三步：启动后端服务

### 3.1 安装后端依赖

1. 打开 **命令提示符**（Win+R → 输入 cmd → 回车）

2. 用 `cd` 命令进入后端目录，例如你把代码解压在了桌面：
   ```
   cd C:\Users\你的用户名\Desktop\club-system\server
   ```

   > 💡 小技巧：在文件资源管理器里打开 server 文件夹，在地址栏输入 `cmd` 回车，就能直接在当前目录打开命令行

3. 输入以下命令安装依赖：
   ```
   npm install
   ```
   等待安装完成（可能需要 1-2 分钟）

### 3.2 配置环境变量

1. 在 `server` 文件夹里找到 `.env.example` 文件
2. **复制**这个文件，把副本**重命名**为 `.env`（注意：文件名就是 `.env`，没有其他名字）
3. 用记事本打开 `.env`，内容如下：
   ```
   PORT=3000
   MONGODB_URI=mongodb://localhost:27017/club-system
   JWT_SECRET=your-jwt-secret-key-here
   JWT_EXPIRES_IN=7d
   ```
4. 如果你的 MongoDB 装在本机，不需要改 MONGODB_URI
5. 把 `your-jwt-secret-key-here` 改成任意字符串，例如 `my-secret-123`

### 3.3 初始化测试数据

在 server 目录的命令行中输入：
```
node seed.js
```

看到以下输出就说明成功了：
```
MongoDB 已连接，开始初始化数据...
种子数据初始化完成！
测试账号:
  管理员: admin / 123456
  社团管理员: zhangsan / 123456
  普通学生: lisi / 123456, wangwu / 123456
```

### 3.4 启动后端服务

在 server 目录的命令行中输入：
```
node app.js
```

看到以下输出就说明后端启动成功了：
```
MongoDB 已连接: localhost
服务器已启动: http://localhost:3000
```

> ⚠️ **注意**：这个命令行窗口不要关闭！关闭了后端就停了。
> 需要开新的命令行窗口来做其他操作。

### 3.5 验证后端是否正常

打开浏览器，访问：http://localhost:3000/api/health

如果看到：
```json
{"code":0,"message":"服务运行正常","data":{"timestamp":"..."}}
```
说明后端一切正常！🎉

## 第四步：用 HBuilderX 运行前端

### 4.1 导入项目到 HBuilderX

1. 打开 **HBuilderX**
2. 菜单栏 → **文件** → **导入** → **从本地目录导入**
3. 选择 `client-hbuilderx` 文件夹（不是 client 文件夹！）
4. 点击「导入」

### 4.2 运行到浏览器（H5模式）

1. 在 HBuilderX 左侧项目管理器中，选中 `client-hbuilderx` 项目
2. 菜单栏 → **运行** → **运行到浏览器** → **Chrome**
3. 等待编译完成，浏览器会自动打开

### 4.3 运行到微信开发者工具（小程序模式）

1. 在 HBuilderX 左侧项目管理器中，选中 `client-hbuilderx` 项目
2. 菜单栏 → **运行** → **运行到小程序模拟器** → **微信开发者工具**
3. 如果是第一次，HBuilderX 会要求你设置微信开发者工具的安装路径：
   - 点击菜单 **工具** → **设置** → **运行配置**
   - 找到「微信开发者工具路径」
   - 填入你的安装路径，例如：`C:\Program Files (x86)\Tencent\微信web开发者工具`
4. 还需要在微信开发者工具中开启「服务端口」：
   - 打开微信开发者工具
   - 菜单 → **设置** → **安全设置**
   - 开启 **「服务端口」**
5. 回到 HBuilderX，再次运行到微信开发者工具

> ⚠️ **微信小程序注意事项**：
> - 微信小程序不能访问 `localhost`，需要在微信开发者工具中：
>   - 点击右上角 **「详情」**
>   - 勾选 **「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」**
> - 或者把 `utils/request.js` 中的 `127.0.0.1` 改成你的电脑局域网 IP

## 常见问题

### Q: npm install 很慢怎么办？
设置淘宝镜像源：
```
npm config set registry https://registry.npmmirror.com
```
然后重新运行 `npm install`。

### Q: 启动后端报错 "MongoServerError: connect ECONNREFUSED"
MongoDB 没有启动。解决方法：
- Windows: 打开「服务」（Win+R → services.msc），找到 MongoDB，右键「启动」
- 或在命令行运行：`net start MongoDB`

### Q: 微信开发者工具里页面空白
1. 确认后端服务 `node app.js` 正在运行
2. 确认勾选了「不校验合法域名」
3. 检查 `utils/request.js` 中的 BASE_URL 是否正确

### Q: HBuilderX 编译报错
1. 确认导入的是 `client-hbuilderx` 文件夹
2. 菜单 → 工具 → 插件安装 → 安装 `uni-app（Vue3）编译器`
3. 重新运行

### Q: 文件夹里看不到 .env 文件
Windows 默认隐藏以 `.` 开头的文件。在文件资源管理器 → 查看 → 勾选「隐藏的项目」。

## 项目文件夹说明

```
club-system/
│
├── server/                 ← 后端（你需要在这里运行 npm install 和 node app.js）
│   ├── app.js             ← 后端入口文件
│   ├── seed.js            ← 种子数据脚本
│   ├── .env.example       ← 环境变量模板（复制为 .env）
│   ├── config/            ← 配置文件
│   ├── models/            ← 数据模型
│   ├── routes/            ← API 路由
│   ├── middleware/         ← 中间件
│   └── utils/             ← 工具函数
│
├── client-hbuilderx/       ← 前端 HBuilderX 版本 ✅ 导入这个到 HBuilderX
│   ├── manifest.json      ← 项目配置
│   ├── pages.json         ← 页面配置
│   ├── App.vue            ← 根组件
│   ├── main.js            ← 入口文件
│   ├── pages/             ← 所有页面
│   ├── api/               ← API 封装
│   ├── utils/             ← 工具（request.js 在这里改服务器地址）
│   └── static/            ← 静态资源
│
├── client/                 ← 前端 CLI 版本（可忽略）
└── docs/                   ← 文档
```
