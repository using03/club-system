### 4.2 开发过程中修复的问题记录

以下是在开发和调试过程中发现并修复的问题，记录在此供参考：

#### BUG-01：HBuilderX 编译报错 — 可选链语法不兼容

| 项目 | 内容 |
|------|------|
| 现象 | HBuilderX 编译时报 `Unexpected token` 错误 |
| 根因 | 模板中使用了 `?.` 可选链语法（如 `m.user?.nickname`），HBuilderX 默认的 Vue 2 编译器不支持 ES2020 可选链 |
| 影响范围 | `club/detail.vue`、`activity/detail.vue` |
| 修复方案 | 将 `?.` 改为辅助方法（如 `getMemberName(m)`），用 `if` 判断替代 |
| 修复提交 | `fix: 修复 HBuilderX 编译报错（3个问题）` |

#### BUG-02：HBuilderX H5 页面白屏

| 项目 | 内容 |
|------|------|
| 现象 | 微信小程序端可显示页面，H5 端完全白屏 |
| 根因 | `main.js` 使用了 Vue 3 的 `createSSRApp`，但 HBuilderX 默认使用 Vue 2 编译器 |
| 影响范围 | 整个 H5 端 |
| 修复方案 | 将 `main.js` 改为 Vue 2 标准写法 `new Vue({...App})` |
| 修复提交 | `fix: 修复 HBuilderX H5 白屏 — 改为 Vue 2 语法` |

#### BUG-03：Pinia 模块缺失

| 项目 | 内容 |
|------|------|
| 现象 | HBuilderX 编译报 `文件查找失败：'pinia'` |
| 根因 | `main.js` 引入了 pinia，但 HBuilderX 原生项目未安装该依赖 |
| 影响范围 | 项目启动 |
| 修复方案 | 移除 pinia 引入（当前未使用 Pinia store） |
| 修复提交 | 同 BUG-01 |

#### BUG-04："我的社团"跳转到通用列表

| 项目 | 内容 |
|------|------|
| 现象 | 新用户点击"我的社团"显示所有社团而非个人已加入的社团 |
| 根因 | 菜单跳转指向了通用社团列表页 `/pages/club/list`，缺少用户过滤逻辑 |
| 影响范围 | 我的社团、我的活动、报名记录、签到记录 4 个菜单 |
| 修复方案 | 新增 4 个后端接口（my-clubs/my-activities/my-registrations/my-checkins）和 4 个专属前端页面 |
| 修复提交 | `feat: 实现'我的社团/活动/报名/签到'专属页面` |

#### BUG-05：遗漏功能 — 社团活动历史

| 项目 | 内容 |
|------|------|
| 现象 | 社团详情页未展示该社团的活动历史 |
| 根因 | 需求文档要求"社团信息展示（成立时间、活动历史）"，但开发时遗漏了活动历史部分 |
| 影响范围 | 社团详情页 |
| 修复方案 | 新增 `GET /api/clubs/:id/activities` 接口，前端社团详情页增加活动历史区域 |
| 修复提交 | `feat: 补充遗漏功能 — 社团活动历史 + 图片上传存储` |

#### BUG-06：图片上传功能缺失

| 项目 | 内容 |
|------|------|
| 现象 | 数据模型有 images/coverImage/logo 字段，但无上传接口，数据库中全为空 |
| 根因 | 课题要求"MongoDB 存储半结构化的活动图文数据"，但开发时仅创建了字段未实现上传 |
| 影响范围 | 社团 Logo、活动封面图、活动图片集 |
| 修复方案 | 新增 `POST /api/upload` 图片上传接口 + multer 文件处理 + 静态文件服务 |
| 修复提交 | 同 BUG-05 |
